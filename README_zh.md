# 农机作业中文语音命令数据集

本数据集面向**农机（拖拉机犁耕）作业环境下的长音频自动语音识别（ASR）**。每个子集包含带有拖拉机背景噪声及人声命令的连续长音频，并附有按序排列的命令转录文本。本数据集配套论文 _《基于定制大模型的农机语音命令识别》_（审稿中，2026）使用。

> 论文所研究的 ASR 系统**以长音频作为输入**，分段由系统的下游环节完成。因此本仓库中的音频以**定长 5 秒切片**（原始长录音的连续、不重叠窗口）形式提供，`transcript.txt` 是整段录音的**有序命令列表**。按文件名顺序拼接所有切片即可还原原始长音频。

## 概述

本数据集采用"直接录制 + 合成"的混合方法构建，以模拟不同的农机作业场景。共包含三个录音集合：

| 录音集合 | 说明 | 拖拉机 | 省份 |
|---|---|---|---|
| **RealRec** | 真实录音，含口音真实人声（ACC），由安装在挡风玻璃上的手机在田间作业时录制 | 东风 2004-5A (G4) | 江苏宿迁 |
| **SynRec DF** | 混合录音：人声命令叠加在东风拖拉机的背景噪声录音上 | 东风 2004-5A (G4) | 上海松江 |
| **SynRec KQ** | 混合录音：人声命令叠加在久保田拖拉机的背景噪声录音上 | 久保田 M704-KQ (G4) | 江苏宿迁 |

两个混合录音集合（SynRec DF 与 SynRec KQ）各自包含**相同的三种声音类型**：

- **RV (STD)** —— 标准（无口音）**真实**人声
- **SV (STD)** —— 标准（无口音）**合成**人声（讯飞 TTS）
- **SV (ACC)** —— 带口音**合成**人声（讯飞 TTS，河南口音）

采集设备为手机，采集时参数设置为**单声道 M4A、48 kHz 采样率、16 位位深**。本仓库提供的 WAV 切片为处理后的波形。

## 子集说明

- **RealRec (ACC)** —— `data/realrec_acc/`。三段真实录音，由安装在东风 2004-5A (G4) 拖拉机挡风玻璃上的三部手机（切片文件名前缀 `2_`、`3_`、`4_`）在江苏宿迁犁耕作业时录制。操作员带东北口音。这是唯一一个背景噪声与命令在田间实地同时采集的子集。

- **标准真实人声混合录音 (RV STD)** —— `data/synrec_df_rv_std/` 与 `data/synrec_kq_rv_std/`。在安静环境中录制的真实人声命令，与拖拉机背景噪声录音混合。自然人声、无口音播报。两个文件夹仅在背景噪声来源上不同：东风拖拉机噪声（录制于上海松江，DF）与久保田拖拉机噪声（录制于江苏宿迁，KQ）。

- **标准合成人声混合录音 (SV STD)** —— `data/synrec_df_sv_std/` 与 `data/synrec_kq_sv_std/`。使用讯飞在线 TTS 合成（无口音设置）的命令，与对应拖拉机的背景噪声录音混合。

- **口音合成人声混合录音 (SV ACC)** —— `data/synrec_df_sv_acc/` 与 `data/synrec_kq_sv_acc/`。使用讯飞在线 TTS 合成（河南口音设置）的命令，与对应拖拉机的背景噪声录音混合。

## 音频格式

- **容器：** WAV（PCM）
- **切片长度：** 5.00 秒（连续、不重叠；每段录音最后一个切片可能更短）
- **采样率：** 48000 Hz（RealRec）/ 16000 Hz（SynRec 子集）
- **声道：** 单声道（1）
- **位深：** 16 位

## 转录文本格式

每个子集有一份 `transcript.txt`，包含整段录音的**有序命令列表**，每行一条命令（UTF-8，`\n` 换行）。行顺序与命令在音频中出现的顺序一致。不提供按切片或按时间戳的对齐——对齐有意留给 ASR 系统的下游分段环节完成。

示例（`data/realrec_acc/transcript.txt`）：

```
落犁
起犁
转弯
落犁
起犁
...
```
